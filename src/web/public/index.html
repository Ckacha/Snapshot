Messages you saved get deleted? SnapShot will make sure something like that will never happen again

Connect with Slack

How it works

  1. Click Connect with Slack and approve.
  2. On any message, press Save for later, or go to More actions → Watch for deletion. Either one saves that message!
  3. If that message ever gets deleted, SnapShot will notify you what the deleted message was!

SnapShot only watches messages you save after you first connect it to Slack. Anything saved before that isn't covered.

What connecting allows

  • Reading messages in channels and DMs you can already see, to check whether watched ones still exist.
  • Seeing what you save for later, so saved messages get watched automatically.

In case you would like to revoke your token for any reason (hi reviewer), remove Snapshot from your Slack apps!
